# Trainy Task Summaries

This directory is the project's concise working memory. All files in this
directory must be written in English.

Create one Markdown file for each completed task. Use a descriptive filename,
for example `frontend-auth-foundation.md` or
`internship-application-workflow.md`.

Each summary should contain:

- task scope and outcome;
- files or systems changed;
- important architecture or business decisions;
- dependency and lockfile changes;
- verification commands with their actual results;
- known limitations or checks blocked by the environment;
- local commit information, when applicable;
- suggested next steps.

Keep summaries factual and concise. Do not include secrets, credentials,
personal data, or copied command output that does not help future work.
